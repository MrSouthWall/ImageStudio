# 图作间 · Image Studio

**[在线使用](https://mrsouthwall.github.io/ImageStudio/)** · [下载 HTML](https://github.com/MrSouthWall/ImageStudio/raw/refs/heads/main/index.html)

一个单文件的 AI 图片创作工作台。支持连续对话生图、局部修改、参考图复用和本地图库，下载一个 HTML 就能使用。

## 使用

打开本仓库的 GitHub Pages 站点，或下载 `index.html` 后用浏览器打开。首次使用在左下角「连接设置」填写自己的 API Key 和接口地址，输入画面描述并发送。

生图需要联网，费用由所配置的 API 服务收取。本仓库和网页不会提供公共密钥或代付额度。使用兼容接口时，服务端须允许浏览器跨域访问。

## 功能

- 对话创作与直接生图，支持 GPT Image 2.6 / 2.5 Sunburst、Flare。
- GIF 动图支持文字或静态参考图生成，可设置 2–16 帧和每帧时长；在「更多 → 输出格式」中选择，需接口具备 GIF 权限。
- 遮罩编辑与标记引导；图片可以上传、粘贴或从图库复用。
- 生图参数自动或默认起步，可一键恢复；提供图片输出的大约费用及模型画质价格对照。
- 统一图库，区分生成和上传图片，支持删除及多选打包下载。
- 对话搜索、排序、置顶、归档、最近删除；侧栏可以收起和调整宽度。
- 完整数据备份和恢复，方便更新 HTML 或迁移到另一个浏览器。

## 数据与密钥

对话、原图、草稿和设置保存在当前浏览器，不会提交到这个 GitHub 仓库。清理浏览器数据、切换浏览器或使用不同网站地址，都可能影响原数据的读取，请定期备份。

生成请求会直接发送到你配置的接口地址，包含该次请求所需的 API Key、提示词和图片等内容。密钥保存在本机浏览器，未加密；请仅使用可信设备和接口。

费用显示是图片输出的参考估价，不包含输入、预览、对话及其它工具费用。自动尺寸按横向 1080P（1920×1088）、自动画质按 high 估算，不会改变实际发送的自动参数。人民币按用户设置的汇率换算，最终以服务商账单为准。

## 备份与更新

在「设置 → 数据备份」中导出完整 ZIP，再更新文件。需要迁移时，在新文件或新浏览器中导入该 ZIP，校验并确认后恢复。

- 备份包含本地对话、原图、各对话草稿、参考图、编辑图层、图库状态及已保存设置。
- API Key 默认不导出，可单独勾选包含。备份文件未加密。
- 导入会替换当前工具的数据，不会合并；请先备份本机现有内容。
- 单份备份及解压数据上限为 1 GB；不包含服务端临时文件正文或云端会话本体。
- 图库「批量下载」仅导出图片，完整迁移应使用设置中的备份 ZIP。

直接打开本地文件时，建议在原位置、原文件名上覆盖更新。网站与本地文件使用不同的浏览器存储，首次从本地文件迁移到网站时请使用备份导入。
