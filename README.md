# 图作间 · Image Studio

**[在线使用](https://mrsouthwall.github.io/ImageStudio/)** · [使用说明](#使用说明)

一个 AI 图片创作网站，支持连续对话生图、局部修改、参考图复用和本地图库。

## 使用说明

### 开始使用

1. 打开侧栏底部的「连接设置」，填写自己的 API Key 和接口地址。默认使用 OpenAI，也可填写允许浏览器跨域访问的兼容接口。手机端先点左上角展开侧栏。
2. 输入画面描述，按 Enter 发送，按 Shift + Enter 换行。
3. 需要参考图时，点击附件按钮从图库选择或上传，也可以拖入或粘贴。每次最多添加 16 张。

生图需要联网，费用由所配置的 API 服务收取。网站没有公共密钥或代付额度。

### 创作与局部编辑

| 方式 | 操作 |
| --- | --- |
| 对话创作 | 沿已有对话继续描述和修改。默认使用 GPT-6.1 Sol，可在顶部切换对话模型。 |
| 直接生图 | 在输入框底部切换创作方式。每次通过 Images API 发送当前提示词和参考图。 |
| 遮罩编辑 | 在图片上打开「局部编辑」，用蓝色涂抹要替换的位置，点「使用选区」并描述修改。两种创作方式均支持，结果会保留编辑底图中选区外的像素。 |
| 标记引导 | 用红色圈选、箭头或画笔指出目标，点「使用标记」并描述修改。应用后会自动切换到直接生图，模型也可能改动标记之外的区域。 |

一次编辑使用一种方式。编辑器支持橡皮、撤销、重做和清除。大图使用长边最多 1920 像素的编辑副本，原图会保留，选区保护以编辑副本为准。

发送后，输入区会清空参考图、选区和标记，消息与图库仍保留图片。继续编辑时，可在结果图上重新选择，或从消息的「再次使用」恢复输入。

### 生图参数与费用

- 图片模型支持 GPT Image 2.6 和 2.5 的 Sunburst、Flare。模型菜单中的信息按钮提供低、中、高画质的参考价格。
- 默认使用自动尺寸、画质、复杂度、背景和审核，输出 1 张 PNG，预览关闭。「更多 → 恢复默认设置」可重置生图参数，同时保留模型、提示词、参考图和对话。打开已有草稿会恢复该草稿的设置。
- 生成 GIF 时，选择 GPT Image 2.6，在「更多 → 输出格式」选择 GIF。可设置 2–16 帧，每帧 20–2000 毫秒，默认 9 帧、每帧 200 毫秒。可添加静态参考图，在提示词中描述主体、动作和循环方式。接口需具备 GIF 权限，GIF 不支持遮罩或流式预览。
- 输入区下方的金额只估算图片输出。自动尺寸按横向 1080P（1920×1088）、自动画质按 high 估算，实际请求仍使用自动参数。人民币按设置中的汇率换算，默认值 7 仅供参考。GIF 和 SVG 暂无估价，最终费用以服务商账单为准。

### 图库与对话

- 图库可按生成或上传来源筛选，可从附件菜单复用旧图。「批量下载」支持多选或全选当前筛选结果并导出图片 ZIP。删除图库图片后，历史或草稿仍引用的原图会保留。
- 对话支持搜索标题和消息、重命名、置顶、排序、归档，以及从最近删除中恢复。
- 桌面侧栏可收起，拖动右边缘可调宽，双击右边缘可恢复默认宽度。窄屏通过左上角按钮打开侧栏。

### 数据与备份

对话、原图、草稿和设置保存在当前浏览器。生成请求会把所需的 API Key、提示词和图片发往配置的接口。API Key 在浏览器中以明文保存，共享设备用完后可在「连接设置」中清除。

1. 在「连接设置 → 数据备份」点击「导出完整备份」，保存 ZIP。从旧版 HTML 迁移时，先在原位置用原来的浏览器打开旧版并导出。
2. 在目标网站或浏览器中点「导入备份」，选取 ZIP 并核对对话、消息和图片数量。
3. 如需保留目标浏览器现有数据，先导出一份备份。关闭其他图作间标签页，点「确认替换并恢复」。导入会替换当前数据，恢复后页面自动刷新。

- 备份包含本地对话、原图、各对话草稿、参考图、编辑图层、图库状态及已保存设置。
- API Key 默认不导出，可单独勾选包含。备份文件未加密。导入不含 Key 的备份时，只有接口地址一致才会保留目标浏览器原有的 Key。
- 早期完整备份可直接导入。单份备份及解压数据上限为 1 GB，备份不包含服务端临时文件正文和云端会话。
- 换浏览器、改网站地址或清除浏览器数据前，可先导出完整 ZIP。在同一浏览器访问原 GitHub Pages 地址，网站更新后仍会读取现有数据。图库的批量下载只保存图片。

## 本地开发

使用 Node.js 24 和 npm。在仓库根目录运行：

```sh
npm ci
npm run dev
```

`index.html` 和 `src/main.tsx` 是网站入口。源码按用途组织。

- `src/components/` 存放界面组件。
- `src/lib/` 存放接口、图片处理和浏览器存储逻辑。
- `src/styles/` 和 `src/assets/` 存放样式和网站资源。

`npm run build` 生成网站目录 `dist/`，`npm run preview` 本地预览构建结果。

## 部署

把完整的 `dist/` 部署到静态网站托管服务。使用 GitHub Pages 时，在仓库的 **Settings → Pages → Source** 选择 **GitHub Actions**，由 `main` 分支上的工作流构建并发布。
