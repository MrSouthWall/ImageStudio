# 图作间使用指南

[在线使用](https://mrsouthwall.github.io/ImageStudio/) · [返回项目首页](../README.md)

## 生成第一张图

1. 点右上角「连接 API」，填入自己的 API Key，然后点「完成」。接口地址默认是 OpenAI。使用兼容服务时，填入服务商提供的地址，接口需允许浏览器跨域访问。
2. 回到「创作台」，写下想要的画面，例如「一座漂浮在云海上的玻璃温室，晨光穿过薄雾，带有胶片质感」。点「生成」或按 Enter 发送，按 Shift + Enter 换行。
3. 发送后会进入「对话」。在「画布」查看生成的图片，切到「对话过程」可回看提示词和回复。

生成费用由所选的 API 服务商收取。请求会把 API Key、提示词和所需图片发给该服务。API Key 以明文保存在当前浏览器，共用设备上用完可在「接口连接」点「清除」。

## 继续创作与添加参考图

在输入框下方选择创作方式。

- **对话创作**沿用当前对话的上下文。出图后可以接着说「把背景改成夜空，保留温室和构图」。所用服务需支持带图片生成工具的 Responses API。
- **直接生图**每次使用本次的提示词和参考图，适合独立尝试不同方案。所用服务需支持 Images API。

点「参考图」（窄屏显示为加号）可以上传图片或从图库选择，也可以直接拖入或粘贴。一次最多添加 16 张。想把生成结果用到下一次创作，打开图片的「⋯」菜单，点「用作参考图」。

<summary>图片参数、动图与费用</summary>

- 输入框下方的「参数」可选图片模型、尺寸、画质、张数和输出格式。默认输出 1 张 PNG，可通过「恢复默认设置」重置图片参数。
- 生成动图时，选用 GPT Image 2.6 系列，再到「参数 → 输出格式」选择「GIF 动图」。可以添加静态参考图，在提示词里描述动作和循环方式。支持 2–16 帧，每帧 20–2000 毫秒。生成 SVG 也需选用 2.6，使用纯文字提示词，每次生成一张。服务商可能要求开通对应格式的权限。
- 「图片输出预估」按图片模型和参数估算。尺寸和画质设为自动时，预估按 1920 × 1088 和高画质计算。对话、参考图输入和流式预览等用量可能另计，最终费用以服务商账单为准。

## 局部编辑

1. 在生成图或图库图片下方点「局部编辑」。如果图片已经在输入框中，点参考图缩略图上的「编辑」。
2. 选择编辑方式。
   - **选区编辑** · 用蓝色画笔涂出要修改的区域，点「使用选区」。结果保留编辑底图中选区外的像素。
   - **标记引导** · 用红色圈选、箭头或画笔指出目标，点「使用标记」。应用后会切换到「直接生图」，标记以外的区域也可能变化。
3. 回到输入框，写清楚要怎么改，例如「把选区内的灯改成暖黄色」，再点「生成」。下次修改时，可以在结果图上重新选择区域。

长边超过 1920 像素的图片会先生成一份缩小的编辑副本，选区保护以这份副本为准。对话消息的「再次使用」可以把本次提示词、参考图和编辑图层填回输入框。

## 找回和复用创作

- **找对话** · 在左侧列表搜索标题或消息，手机上先点「对话列表」。桌面可按 ⌘K 或 Ctrl+K 跳到搜索。对话也可以置顶、归档，或从「最近删除」恢复。
- **下载作品** · 在「图库」按「生成」或「上传」筛选。点「批量下载」，选好图片后点「下载 ZIP」。
- **收藏提示词和参考图** · 点输入框下方的书签，选择「收藏当前输入」。也可以在消息旁点「收藏」，或从图片菜单选择「收藏为参考图」。
- **取用收藏** · 在书签菜单打开「使用收藏」。带提示词的收藏可填入当前输入框，或选「在新创作中使用」以保留原草稿。纯参考图收藏可点「添加参考图」直接追加。

## 备份和迁移

图作间把对话、图片、草稿和收藏保存在当前浏览器。换设备、换浏览器、改站点地址或清除浏览器数据前，可导出完整备份。

1. 点右上角「API 已配置」或「连接 API」，打开「本地数据」，点「导出完整备份」保存 ZIP。单份备份上限为 1 GB。
2. 在目标浏览器打开图作间的「本地数据」，点「导入备份」。选取 ZIP，核对显示的对话、消息、收藏和图片数量。
3. **导入会替换目标浏览器的现有创作数据与设置。** 如需保留现有数据，先在目标浏览器导出一份备份。关闭其他图作间标签页，再点「确认替换并恢复」。完成后页面会自动刷新。

备份 ZIP 未加密，默认省略 API Key。需要一并迁移时可勾选「导出时包含 API Key」。导入省略密钥的备份时，接口地址一致才会保留目标浏览器已有的密钥。

图库的「批量下载」只导出选中的图片，迁移对话和草稿请用完整备份。对话工具生成的服务端临时文件需在对话中单独下载。

从旧版单文件 HTML 迁移时，先在原浏览器中从原位置打开旧版，导出完整备份。
